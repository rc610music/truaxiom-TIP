# TIP Registry

**Document ID:** REG-0001  
**Status:** Draft v0.1  
**Sprint:** Sprint 001 — Foundation

---

## Purpose

The TIP Registry is the canonical catalog of platform systems, modules, agents, applications, products, documents, and decisions.

Every major component receives a permanent ID so the platform can be discussed, documented, implemented, searched, and extended without ambiguity.

| Prefix | Meaning |
